# LuminaBox_FE

Frontend of LuminaBox, a multi-stall mooncake marketplace (course PRN232). React 19, TypeScript, Vite, Tailwind CSS v4.

```bash
pnpm install
cp .env.example .env
pnpm dev
```

The dev server runs on `http://localhost:5173`. With `VITE_USE_MOCK=true` no backend is needed.
